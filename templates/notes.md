# ui-progress notes for this project

What every agent working on this project's UI history must know and respect: what the user
asked for, and what was found out the hard way. Read the section for the job at hand, and
"Everywhere", before starting. Add a note as soon as you learn one; remove notes that no
longer apply. One bullet per note: what to do or avoid, why, and where it came from (the
user and the date, or what showed it). Where a setting can enforce a note (`capture.unsafe`,
`capture.exclude`, `capture.waitFor`, `screens.json`), set it too and say so in the note.
